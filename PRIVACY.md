# Privacy

Image Workshop stores projects, prompts, tags, accepted image versions, and favourite state locally in its sandbox. Imported originals remain immutable. PNG/JPEG exports and PDF contact sheets are written only to destinations you choose. Deleting a project deletes its stored image versions after its metadata deletion succeeds.

Image creation occurs in Apple's Image Playground sheet. Apple's current model uses Private Cloud Compute; prompts and reference imagery are handled by Apple's system experience. No external provider is opted into by this app. Check Apple's current privacy disclosures and system settings before using sensitive content.

Prompt assistance uses the on-device Foundation Models model, when available. The app has no analytics, telemetry SDK, account, advertising, or application-operated server. No App Store seller identity or private signing team is included.

The workspace may retain unreferenced files if the app is interrupted between a file write and a database save; it does not delete unknown files during launch. Back up the complete sandbox library when preserving work.
