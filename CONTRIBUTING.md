# Contributing

Use Xcode 27, macOS 27, and Swift 6. Keep UI/model state on the main actor, isolate file processing, and preserve cancellation and error paths. Run the core tests and native workflow before proposing a change. Explain user-visible behaviour and relevant verification with concise Conventional Commit messages.

Check light/dark appearance, window resizing, keyboard-only interaction, VoiceOver, increased contrast, and model availability. Do not add private signing identifiers or generated content presented as a verified service result. Remove personal data from logs and screenshots.
